🖥 Layout Editor

Keep several layouts as presets and switch which is live as the stream changes. Drag each panel where you want it (drag its bottom-right corner to resize), Save, then Make Live — the overlay uses the live preset on its next load (hit "Reload OBS Overlay" in Bot Control to swap it instantly). Panels show sample content and only air while their game is running. Positions are percentages, so they hold at any OBS source size.

Alerts & Tools

Live Alert Log

The most recent events as they hit the overlay — subs, raids, drops, redemptions and bot actions. Refreshes while this tab is open and pauses when it is hidden.

Test Alerts

Fire a sample of any alert onto the overlay to preview and position it. Each uses obvious fake data and clears itself exactly like the real alert.

Alerts On/Off

Master switch per alert type. A disabled type never shows on the overlay — by any path, including its test button. All on by default.

Alert Sounds

Upload a short sting per alert type (mp3, ogg, wav, m4a — 2MB max). The overlay plays it instead of the default when that alert fires. Set its volume, Test to preview, Clear to go back to the default sound.
