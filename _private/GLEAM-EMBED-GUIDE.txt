================================================================================
  HOW TO EMBED A GLEAM.IO GIVEAWAY ON THE PHANTOMACE GIVEAWAY PAGE
================================================================================


STEP 1: CREATE YOUR GIVEAWAY ON GLEAM.IO
-----------------------------------------

  1. Go to https://gleam.io and log in (or create a free account)
  2. Click "New Competition" or "New Campaign"
  3. Fill in:
     - Campaign name (e.g. "September 2026 Monthly Giveaway")
     - Prize description
     - Start and end dates
  4. Add entry methods — these are actions users complete for entries:
     - Follow on Twitch
     - Join Discord
     - Follow on Twitter/X
     - Visit a URL
     - Custom actions (e.g. "Paste your bonus code")
  5. Under entry methods, add a "Secret Code" or "Custom Action" entry
     for bonus codes:
     - Label it something like "Bonus Code" or "Hype Train Code"
     - This is where viewers will paste the codes from the website/chat
  6. Click "Save" or "Launch" when ready


STEP 2: GET THE EMBED CODE
---------------------------

  1. In Gleam, open your competition
  2. Click "Install" or "Embed" (usually in the top bar or sidebar)
  3. Select "JavaScript Widget" (NOT the iframe version)
  4. You'll see code that looks like this:

     <a class="e-widget no-button"
        href="https://gleam.io/XXXXX/your-giveaway-name"
        rel="nofollow">Your Giveaway Name</a>
     <script type="text/javascript"
        src="https://widget.gleam.io/e.js" async="true"></script>

  5. Copy this entire code block


STEP 3: PASTE INTO THE GIVEAWAY PAGE
--------------------------------------

  1. Open: giveaway.html

  2. Find this section (around lines 47-58):

     <!-- Gleam.io Embed -->
     <div class="gleam-embed" id="gleamEmbed">
       <div class="gleam-placeholder" id="gleamPlaceholder">
         <p>The giveaway widget will appear here once the monthly
         competition is set up.</p>
         <p style="font-size: 11px; color: var(--text-dim);">
         Powered by Gleam.io</p>
       </div>
       <!--
         Replace the placeholder above with your Gleam.io embed code:
         ...
       -->
     </div>

  3. Delete the placeholder div and the comment block, and paste your
     Gleam embed code in their place. It should look like:

     <div class="gleam-embed" id="gleamEmbed">
       <a class="e-widget no-button"
          href="https://gleam.io/XXXXX/your-giveaway-name"
          rel="nofollow">Your Giveaway Name</a>
       <script type="text/javascript"
          src="https://widget.gleam.io/e.js" async="true"></script>
     </div>

  4. Save the file


STEP 4: UPDATE THE GIVEAWAY DETAILS
-------------------------------------

  While you're in giveaway.html, update the banner text too:

  1. Find line ~37:
     <div class="giveaway-month" id="giveawayMonth">September 2026</div>

     This auto-updates to the current month via JavaScript, so you can
     leave it as-is.

  2. Find line ~38:
     <h2 class="giveaway-title" id="giveawayTitle">Monthly Giveaway</h2>

     Change "Monthly Giveaway" to your actual prize name, e.g.:
     "Win a Custom Commander Deck"

  3. Find line ~39:
     <p class="giveaway-prize" id="giveawayPrize">Prize details coming
     soon...</p>

     Change to your actual prize description, e.g.:
     "A custom-built Commander deck worth $200, shipped anywhere in the US!"


STEP 5: DEPLOY
---------------

  Push the changes to Cloudflare Pages (or re-deploy however you prefer).
  The Gleam widget will load on the giveaway page automatically.


MONTHLY UPDATES
----------------

  Each month when you start a new giveaway:

  1. Create a new competition on Gleam.io
  2. Get the new embed code
  3. Replace the old embed code in giveaway.html with the new one
  4. Update the title and prize description if needed
  5. Re-deploy

  The bonus entry codes from Phamily Time and hype train code drops
  work independently — they don't need to change. Viewers paste their
  codes into whatever "Secret Code" or "Custom Action" entry method
  you set up in Step 1.


TIPS
-----

  - The Gleam JavaScript widget auto-resizes to fit the container.
    The .gleam-embed CSS gives it a dark background and rounded border
    that matches the site theme.

  - If the widget looks too light/bright, Gleam has a "Dark Mode"
    option in the widget settings. Use it for better visual consistency.

  - The "Secret Code" entry method in Gleam validates that codes are
    unique per user, so each bonus code can only be used once.

  - Hype train codes expire after 5 minutes on the website, but if
    someone already copied it, they can still paste it into Gleam
    after that window closes. The expiry just removes visibility,
    not validity. If you want to invalidate codes in Gleam too,
    you'd need to manage that on the Gleam side.
