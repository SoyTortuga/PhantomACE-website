Keep it to yourself — Enshrouded has no per-player whitelist, so anyone with this password is in.

  1. Own Enshrouded on Steam and have it updated to the current version. A version mismatch is refused at the door.
  2. In game, open Play → Servers → Add Server (or the Favourites tab).
  3. Paste the address above, including the port.
  4. Enter the password when prompted, then create or pick your character.
