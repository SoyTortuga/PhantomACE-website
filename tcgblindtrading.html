Blind Trading Tool

A real-time, two-player trade-window simulator for Magic & Pokémon TCG — the old-school Rocket League trade UI, rebuilt for streaming.

Two people connect with a shared trade code and build up an offer of real cards — pulled live from each game's database with real images and pricing — in a synced trade window. Neither side locks in until both players confirm at once: the "blind" reveal the tool is named for. It's made for on-stream trading content and demos, not a marketplace — no accounts, no payments, nothing actually changes hands.

What it does

🔗

Live trade sessions

Create a short trade code, share it, your partner joins — both sides see the same state update in real time over WebSocket.

🂠

Two games, one trade

Each trade is Magic or Pokémon (never mixed), chosen when the trade is created.

📚

Personal collections

Build named collections of cards you own per game and trade straight from them; quantities track what's already on the table. Stored in your browser — private by design.

📥

Collection import

Paste or upload a CSV from Moxfield, Deckbox, Archidekt or ManaBox to bulk-fill a Magic collection, matched against real printings.

🧑‍🤝‍🧑

Partner profiles

An optional display name and avatar shown to whoever you're trading with.

🔍

Rich card browsing

A responsive, keyboard-navigable card grid with Enter-to-add and a hover zoom preview at higher resolution.

🖥️

Also a desktop app

The same client packages with Tauri into native Windows installers — this is the browser build of it.

🛰️

Hosted backend

The WebSocket server runs on Render with a health check and automatic reconnect, so it rides out the free tier's idle-sleep wake-up.

Real card data, both games

Magic: The Gathering

Card data from Scryfall — USD/foil pricing and "special treatment" badges for borderless, showcase and extended-art printings. A server-side SQLite cache refreshes daily from Scryfall's full bulk snapshot (~113k cards), so search is instant.

Pokémon TCG

Card data from TCGdex, with matching treatment badges for holo, reverse holo and 1st-edition printings — the same trade-window flow as Magic.

Built with

React + TypeScript Vite Tauri (Rust) Node.js + TypeScript ws (WebSocket) better-sqlite3 Scryfall API TCGdex Render
