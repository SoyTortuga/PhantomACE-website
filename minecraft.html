How to join

mc.phantomace.tv

No port needed — the address carries it.

  1. Install the CurseForge app. It's the launcher that installs modpacks for you. Download it here, install, and let it find your Minecraft.
  2. Find the pack. In CurseForge choose Minecraft → Browse Modpacks and search Cursed Walking. You want Cursed Walking — A Modern Zombie Apocalypse. Not the Lite Edition — that's a different pack and won't connect.
  3. Install version v3.3. Open the pack's Versions tab and pick that one rather than Install. The server runs one exact build and a mismatch is refused at the door.
  4. Give it memory. In CurseForge, Settings → Minecraft → Allocated Memory, set at least 4 GB (6 GB if you have it). The default is too low and the pack will crash on load.
  5. Whitelist yourself in the panel on this page, if you haven't.
  6. Play. Launch the pack, Multiplayer → Add Server, paste the address above, and join.
