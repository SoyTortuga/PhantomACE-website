🖥 Overlay Layout

Keep several layouts as presets — "Just Chatting", "Gaming", "Bingo night" — and switch which one is live as the stream changes. Drag each panel where you want it, Save, then Make Live; the overlay uses the live preset on its next load (hit "Reload OBS Overlay" in Bot Control to swap it instantly). Panels show sample content and only air while their game is running. Positions are percentages, so they hold at any OBS source size.
